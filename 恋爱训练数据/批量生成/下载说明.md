# 橄榄子AI训练数据集下载说明

## 数据集信息

- **名称**: 橄榄子AI训练数据集
- **版本**: V2.0
- **总量**: 200万条
- **格式**: JSONL (gzip压缩)
- **大小**: 100MB (压缩后)

## 文件列表

共20个文件，每个文件10万条数据：

```
olive_batch_0001.jsonl.gz ~ olive_batch_0020.jsonl.gz
```

## 数据格式

每条数据格式：
```json
{
  "instruction": "系统指令",
  "input": "用户问题",
  "output": "完整回复（含思维链和结构化回答）"
}
```

## 下载方式

### 方式1：HTTP下载（推荐）

启动HTTP服务后，使用以下链接下载：

```bash
# 下载所有文件
for i in {001..020}; do
  wget http://服务器地址:8080/olive_batch_${i}.jsonl.gz
done
```

### 方式2：GitHub分批下载

数据已分批推送到GitHub，每批≤50MB。

### 方式3：云存储下载

可上传到阿里云OSS/腾讯云COS，生成临时下载链接。

## 使用说明

1. 解压文件：`gunzip olive_batch_*.jsonl.gz`
2. 合并文件（可选）：`cat olive_batch_*.jsonl > olive_all.jsonl`
3. 按需分割训练集/验证集/测试集
