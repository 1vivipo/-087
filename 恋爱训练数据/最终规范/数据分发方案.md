# 橄榄子AI训练数据分发方案

## 一、数据规模预估

| 项目 | 数值 | 说明 |
|------|------|------|
| 总数据量 | 200万条 | |
| 单条平均大小 | ~800字节 | JSON格式 |
| 总文件大小 | ~1.6GB | 未压缩 |
| 压缩后大小 | ~400MB | gzip压缩 |

## 二、GitHub限制

| 限制项 | 限制值 | 应对策略 |
|--------|--------|----------|
| 单文件大小 | 100MB | 分割文件，每文件≤50MB |
| 单次推送 | 100MB | 分批次推送 |
| 仓库总大小 | 1GB | 只存规范和示例，数据另存 |
| 单次提交文件数 | 无明确限制 | 分批提交 |

## 三、分发方案

### 方案A：GitHub分批推送

**适用场景**：数据量适中，网络稳定

**操作步骤**：
1. 数据分割成多个文件（每个≤50MB）
2. 每次推送1-2个文件
3. 间隔等待，避免触发限制

**文件命名**：
```
olive_train_part001.jsonl.gz  (50MB)
olive_train_part002.jsonl.gz  (50MB)
...
olive_train_part008.jsonl.gz  (50MB)
```

### 方案B：临时公网下载链接

**适用场景**：数据量大，需要快速分发

**可选平台**：

| 平台 | 免费额度 | 特点 |
|------|----------|------|
| 阿里云OSS | 5GB/月 | 国内速度快 |
| 腾讯云COS | 5GB/月 | 国内速度快 |
| 百度网盘 | 2TB | 分享方便 |
| 蓝奏云 | 无限 | 单文件≤100MB |
| 临时文件服务 | 各异 | 快速分享 |

**推荐方案**：
1. **阿里云OSS临时链接**（推荐）
   - 上传到OSS
   - 生成临时下载链接（有效期7天）
   - 链接分享给用户

2. **百度网盘**
   - 上传到网盘
   - 生成分享链接
   - 提取码分享

3. **自建临时服务**
   - 使用transfer.sh
   - 使用file.io
   - 使用gofile.io

### 方案C：本地服务器直传

**适用场景**：有服务器资源

**操作步骤**：
1. 数据打包压缩
2. 启动HTTP服务
3. 提供下载链接

## 四、数据分割策略

### 4.1 按大小分割

```bash
# 每个文件约50万条（约50MB）
总文件: olive_train.jsonl (200万条)
分割后:
  - olive_train_001.jsonl (50万条)
  - olive_train_002.jsonl (50万条)
  - olive_train_003.jsonl (50万条)
  - olive_train_004.jsonl (50万条)
```

### 4.2 按阶段分割

```bash
# 按阶段分开存储
olive_stranger.jsonl    (陌生期 70万条)
olive_familiar.jsonl    (熟悉期 60万条)
olive_ambiguous.jsonl   (暧昧期 50万条)
olive_other.jsonl       (其他 20万条)
```

### 4.3 按类型分割

```bash
# 按数据类型分开
olive_books.jsonl       (书籍数据 80万条)
olive_scenarios.jsonl   (情境数据 60万条)
olive_cases.jsonl       (案例数据 30万条)
olive_techniques.jsonl  (技巧数据 20万条)
olive_mindset.jsonl     (心态数据 10万条)
```

## 五、数据校验

### 5.1 文件校验

每个文件附带MD5校验：
```
olive_train_001.jsonl.gz
olive_train_001.jsonl.gz.md5
```

### 5.2 数据完整性

提供数据统计文件：
```json
{
  "total_count": 2000000,
  "files": [
    {"name": "olive_train_001.jsonl.gz", "count": 500000, "md5": "..."},
    {"name": "olive_train_002.jsonl.gz", "count": 500000, "md5": "..."},
    ...
  ]
}
```

## 六、推荐分发流程

### 阶段一：规范和示例（GitHub）

```
推送到GitHub:
- 设计规范文档
- 示例数据（100条）
- 数据统计说明
```

### 阶段二：小批量测试（GitHub）

```
推送测试数据:
- 测试集（1万条）
- 验证集（1万条）
- 分2-3次推送
```

### 阶段三：完整数据（临时链接）

```
生成临时下载链接:
- 训练集（160万条）
- 打包压缩
- 上传到云存储
- 生成临时链接
```
